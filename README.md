# Git in Practice

A hands-on, beginner-friendly field guide to everyday Git commands and workflows.

## Start here

Open **[index.html](index.html)** in a browser. The page introduces the core workflow and the topics this repository is designed to teach.

## Practice safely

Some Git commands can discard uncommitted work. Use a disposable branch or temporary files when experimenting with `git reset` and `git clean`.

## Topics

Repository inspection · staging and commits · branches · undo and recovery · remotes · tags · integrating changes
