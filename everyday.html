Everyday commands

The commands you will use most days: inspect your work, choose what to save, make a snapshot, and review your history.

A quick daily loop

Make a small change and record it as a clear local snapshot.

  1. 1

    Inspect

    See what changed.

    git status
  2. 2

    Select

    Stage related files.

    git add page.html
  3. 3

    Save

    Name the snapshot.

    git commit -m "Add guide"
  4. 4

    Review

    Read recent history.

    git log --oneline

These commands work locally. Push a finished commit when you are ready to share it.

Inspect your setup and work

git version

Prints the installed Git version. It is a local, read-only check.

git version

Run it during setup. You might see git version 2.45.1.

LocalRead-only

git status

Shows your current branch and which files are untracked, modified, or staged. It does not change files.

git status
git status --short --branch

Check status before staging, committing, or switching branches.

LocalRead-only

git log --oneline

Lists local commits in a compact form. Add graph options to see how branches and tags connect.

git log --oneline
git log --oneline --decorate --graph --all
LocalRead-only

Select and save your changes

Think of staging as your shortlist for the next commit.

git add

Places selected changes in the staging area. It does not create a commit or contact a remote.

git add index.html
git add everyday.html recovery.html
git add -p

-p lets you stage selected chunks. Use named paths so you can see what you selected.

LocalStages changes

git commit / save with a message

Creates a local snapshot from staged changes. A clear subject makes history easier to scan.

git commit -m "Add command guide"
git commit -m "Fix broken navigation"

Good messages start with a verb and describe one focused change.

LocalCreates history

git commit / write in the editor

The second common form opens your configured editor for a subject and a longer explanation.

git add remotes.html
git commit

Use the editor when a change needs more context. Save and close it to finish the commit.

LocalCreates history

Organize work with branches and tags

git branch

Lists local branches. Add a name to create a branch at the current commit; creation alone does not switch to it.

git branch
git branch docs/branch-workflow
LocalHistory pointer

git checkout

Switches branches and updates working files to match. The -b option creates and switches in one step.

git checkout docs/branch-workflow
git checkout -b docs/new-lesson

Modern Git also has git switch -c docs/new-lesson for creating and switching branches.

LocalChanges active files

git tag

Marks a commit with a memorable name, often for a release. Tags stay local until you push them.

git tag
git tag -a v1.0 -m "First guide release"
git push origin v1.0

An annotated tag includes a message and metadata. git push --tags publishes all local tags.
