Everyday commands

These commands inspect or change local work. The first group does not contact GitHub.

git version

Prints the installed Git version. Local read-only check.

git version

Run during setup; output might look like git version 2.45.1.

git status

Shows the current branch and which changes are untracked, modified, or staged. Local and read-only.

git status
git status --short --branch

Run before staging, committing, or switching branches.

git add

Copies selected file changes into the staging area for the next commit. Does not commit or contact a remote.

git add index.html
git add everyday.html recovery.html
git add -p

-p stages selected chunks. Named paths are a clear starting point.

git commit (save a snapshot)

Creates a local snapshot from staged changes.

git commit -m "Add command guide"
git commit

The second form opens an editor for a longer message. Useful examples: “Document branch workflow,” “Fix recovery page examples,” “Remove outdated starter note.”

git log --oneline

Lists local commits in compact form. Read-only.

git log --oneline
git log --oneline --decorate --graph --all

The graph form visualizes branches and tags.

git branch

Lists local branches; with a name, creates a branch at the current commit. A branch is a local pointer into history.

git branch
git branch docs/branch-workflow

Creating a branch does not switch to it.

git checkout

Switches branches, or in older/common usage restores a file. Switching updates your working files to match that branch.

git checkout docs/branch-workflow
git checkout -b docs/new-lesson

-b creates and switches. Modern Git also offers git switch -c docs/new-lesson.

git tag

Adds a named marker to a commit, often a release. Local unless pushed.

git tag
git tag -a v1.0 -m "First guide release"
git push origin v1.0

An annotated tag stores a message and metadata. git push --tags publishes all tags.

git status
