Fix the latest message

Spotted a typo after committing? Amend can replace the latest local commit message before you share it.

Correct a commit message

Only amend the latest commit, and check whether it has already been shared.

  1. 1

    Inspect

    Check the latest message.

    git log -1
  2. 2

    Correct

    Write the fixed subject.

    git commit --amend
  3. 3

    Review

    Confirm the new commit.

    git log --oneline
  4. 4

    Share

    Push after review.

    git push

The command is --amend

git ammend is a common misspelling, not a Git command. Use git commit --amend to replace the latest commit. The commit ID changes because Git writes a new commit.

git commit --amend -m "Add command guide"

This replaces a typo such as Add commmand guide with Add command guide.

Include a file you forgot to stage

Stage the missing file, then amend without changing the existing message:

git add missed-file.html
git commit --amend --no-edit
Before pushing: amending rewrites the commit. Avoid changing a commit already shared with collaborators unless they agree to the history rewrite.
