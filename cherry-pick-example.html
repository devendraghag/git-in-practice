Practice / Pick one commit

Carry one change across

Cherry-pick copies one commit onto the branch you are on. It is handy when a single fix is useful elsewhere.

Select, switch, copy, review

The original branch stays where it is; the destination gets a new commit.

  1. 1

    Find

    Copy the commit ID.

    git log --oneline
  2. 2

    Switch

    Choose the destination.

    git checkout main
  3. 3

    Pick

    Copy the chosen change.

    git cherry-pick ID
  4. 4

    Review

    Check the new commit.

    git show --stat

Basic syntax

git checkout main
git cherry-pick a1b2c3d

Replace a1b2c3d with the commit ID you found in git log --oneline. Git applies the change and creates a new commit on the current branch.

If there is a conflict

Open each conflicted file, choose the right content, and stage the resolution. Then continue:

git add resolved-file.html
git cherry-pick --continue

To abandon the operation and return to the previous state, use git cherry-pick --abort.
