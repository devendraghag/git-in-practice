Lesson 02 / Recovery tools

Undo and recover

First find where the change lives. Then choose the smallest undo that fixes it. Some commands discard work, so read their warning before trying them.

Correct the latest local commit

Amend changes the most recent commit ID. Use it before you share that commit.

git commit --amend

The common misspelling is git ammend; that is not a Git command. The correct command is git commit --amend. It replaces your latest local commit, changing its message or including newly staged files.

git commit --amend -m "Document branch workflow"
git add missed-file.html
git commit --amend --no-edit
History changes: the old commit ID is replaced. Avoid amending a commit already shared with others unless your team coordinates the rewrite.

When the change is not committed

Unstage keeps your edits. Clean removes only untracked files.

git reset / unstage selected changes

Moves selected changes out of the staging area but leaves the edited file contents alone.

git reset -- path/to/file.html
git restore --staged path/to/file.html

Example: if notes.txt was staged by mistake, reset that path. The edits remain in your working folder.

LocalLeaves file edits

git stash

Shelves tracked edits temporarily so you can switch tasks. It stays local; include -u when you also need to stash untracked files.

git stash push -m "unfinished navigation edit"
git stash list
git stash pop

pop restores and removes the stash entry. git stash apply restores it but keeps the saved copy.

LocalTemporary save

git clean

Deletes untracked files and folders. It cannot remove committed files, but its deletions are not easy to recover.

git clean -n
git clean -fd -- practice-temp/
Risk: this example removes untracked content only inside practice-temp/. First preview it with git clean -nd -- practice-temp/ and verify that the listed files are disposable.
LocalDeletes untracked files

When the change is committed

git revert

Creates a new commit that reverses an earlier commit. This keeps shared history intact and is usually the safer choice for published work.

git revert a1b2c3d
git revert --no-edit a1b2c3d

Choose the commit ID from git log --oneline, then review the new commit.

Local commitPreserves old history

git reset / move the branch back

Moves the current branch pointer to an earlier commit. It changes local history; the mode controls what happens to staged and working changes.

git reset --soft HEAD~1
git reset --mixed HEAD~1
git reset --hard HEAD~1

--soft keeps edits staged. --mixed leaves them unstaged. --hard discards tracked edits as well.

Risk: git reset --hard HEAD~1 removes the latest commit from the current branch and discards its tracked changes from the working tree. Only practice on a disposable branch after checking status and the target commit.
LocalMoves branch history

git rm

Deletes a tracked file from the working folder and stages that deletion for your next commit.

git rm old-notes.txt
git commit -m "Remove outdated starter note"

To keep the file on your computer but stop tracking it, use git rm --cached secret.txt and add it to .gitignore.

LocalStages deletion

Before you undo

  1. Check git status.
  2. Confirm the target with git log --oneline.
  3. Preview removal with git clean -n.
  4. For shared commits, choose git revert instead of rewriting history.
