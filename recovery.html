Undo and recover

Choose an undo command by asking: is the change staged, committed, or only in my working folder?

git commit --amend (often mistyped “git ammend”)

There is no standard git ammend command. The correct spelling is git commit --amend. It replaces the latest local commit with a new one, optionally changing its message or adding staged changes. This rewrites local history; avoid amending a commit already shared with others.

git commit --amend -m "Document branch workflow"
git add missed-file.html
git commit --amend --no-edit

To fix “Add commmand guide,” run git commit --amend -m "Add command guide". The old commit ID changes. Coordinate before rewriting published history.

git reset (unstage selected changes)

Moves changes out of the staging area while leaving edited file contents in place. It changes the index, not commit history or file contents.

git reset -- path/to/file.html
git restore --staged path/to/file.html

Example: after accidentally staging notes.txt, run git reset -- notes.txt; the edit remains unstaged.

git reset (move the current branch back)

Moves the current branch pointer to an earlier commit. This changes local history and, depending on mode, can discard staged or working changes. It does not contact the remote.

git reset --soft HEAD~1
git reset --mixed HEAD~1
git reset --hard HEAD~1

--soft keeps changes staged; --mixed (default) keeps them unstaged; --hard discards tracked working changes too.

Risk: git reset --hard HEAD~1 discards the latest commit from the current branch and its tracked changes from the working tree. Only use it on a disposable branch after confirming git status and the target commit. For published work, prefer git revert.

git clean

Deletes untracked files and folders from the working folder. It does not delete committed files or contact a remote.

git clean -n
git clean -fd -- practice-temp/

Risk: git clean -fd -- practice-temp/ permanently removes untracked files under practice-temp/. First inspect git clean -nd -- practice-temp/; do not use on unbacked-up work.

git stash

Temporarily shelves tracked edits so you can switch tasks. Local only; untracked files require -u.

git stash push -m "unfinished navigation edit"
git stash list
git stash pop

pop reapplies and removes the stash entry. git stash apply reapplies while keeping the saved copy.

git revert

Creates a new commit that reverses an earlier commit. It preserves shared history and is usually safer for published changes.

git revert a1b2c3d
git revert --no-edit a1b2c3d

Use an ID from git log --oneline; review the new commit before pushing.

git rm

Removes a tracked file from the working folder and stages its deletion for the next commit.

git rm old-notes.txt
git commit -m "Remove outdated starter note"

To stop tracking a file but keep it locally, use git rm --cached secret.txt and add it to .gitignore.

Recovery habit

Before a command that discards changes, inspect git status, check the target with git log --oneline, and consider a safety branch. Preview untracked deletion with git clean -n.
