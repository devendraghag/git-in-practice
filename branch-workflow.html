A branch workflow to practice

Make a small change on its own branch, save it, then bring it back to main. A branch keeps unfinished work separate from the main line.

Try the sequence

git status
git checkout -b docs/branch-workflow
git add branch-workflow.html
git commit -m "Document branch workflow"
git checkout main
git merge docs/branch-workflow

The branch and commit are local. The merge updates local history. To share the branch use git push -u origin docs/branch-workflow.
