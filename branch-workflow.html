Branch, commit, merge

Keep the main line tidy while you build one focused change.

  1. 1

    Create

    Start a focused branch.

    git checkout -b
  2. 2

    Commit

    Save the related change.

    git commit
  3. 3

    Return

    Switch to the base branch.

    git checkout main
  4. 4

    Merge

    Bring the branch into main.

    git merge

A branch is a lightweight pointer to a commit. Switching branches updates the files in your working folder.

Try this sequence

git status
git checkout -b docs/branch-workflow
git add branch-workflow.html
git commit -m "Document branch workflow"
git checkout main
git merge docs/branch-workflow

This example uses the same branch and focused commit recorded in this learning repository.

Branch changes are localMerge updates history

Share the branch with others

Push a new branch once to publish it and set its upstream:

git push -u origin docs/branch-workflow

After that, use git push to send later commits on that branch.
